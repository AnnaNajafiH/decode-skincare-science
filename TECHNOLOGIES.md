# Technologies & Tools Used in B.SkinWise

## Frontend Technologies

- **React 18** - JavaScript library for building user interfaces
- **TypeScript** - Typed superset of JavaScript for type safety
- **Vite 5.4.21** - Build tool and development server
- **TailwindCSS** - Utility-first CSS framework for styling

## Libraries

- **jsPDF** - Client-side PDF generation library
- **lucide-react** - Icon library
- **React Hooks** - useState, useEffect, useCallback for state management

## Development Tools

- **npm** - Package manager
- **Git** - Version control
- **VS Code** - Code editor
- **Chrome DevTools** - Browser testing and debugging

## APIs & Features

- **HTML5 Audio API** - For celebration sounds
- **DOM API** - For confetti animations
- **CSS Animations** - @keyframes for motion effects

## Deployment

- **Netlify** - Hosting platform
- **GitHub** - Code repository

## Design Tools

- **Beiersdorf Brand Colors** - #0032A3 (blue)
- **System Fonts** - Helvetica Neue, Arial for logo
- **Responsive Design** - Mobile-first approach
